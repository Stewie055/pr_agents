# Phase 4: Product UI And Operations

## Goal

把单页开发工作台推进为可持续使用的诊断产品界面，并补齐基础运维能力。

## Key Work

- 增加案例列表、案例详情、历史搜索和状态筛选。
- 增强图表工作台：分组、筛选、下载、全屏和说明信息。
- 增强报告区域：报告版本、生成状态、下载和预览入口。
- 增强 Trace 调试台：timeline 过滤、LLM audit 过滤、tool observation 展开和脱敏导出。
- 增加结构化日志、请求 ID、配置校验、健康检查和部署文档。

## Acceptance

- 主界面仍只展示用户可见信息。
- Trace 调试能力独立入口保留，后续可接外部权限系统。
- 前端测试覆盖核心视图和交互。
- README、REQUIREMENTS 和 docs 更新到产品化运行方式。
